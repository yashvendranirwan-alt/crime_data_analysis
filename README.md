# 🕵️ Crime Data Analysis & Visualization

A data analysis and visualization project that explores crime patterns in the United States using **Python, NumPy, Pandas, Seaborn, and Matplotlib**.  
This project aims to uncover insights into crime trends, hotspots, and correlations to support better decision‑making in law enforcement and public safety.

---

## 📌 Objectives
- Analyze crime datasets to identify patterns and anomalies.
- Visualize crime distribution across states, years, and categories.
- Explore correlations between socio‑economic factors and crime rates.
- Provide clear, interactive charts for better understanding.

---

## 🛠️ Tech Stack
- **Python** – Core programming language
- **NumPy & Pandas** – Data cleaning and manipulation
- **Seaborn & Matplotlib** – Statistical visualization
- **Jupyter Notebook** – Interactive analysis environment
